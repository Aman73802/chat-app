# 💬 Real-Time Chat Application

A full-stack real-time chat application built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js) with **Socket.IO** for real-time communication. It allows users to register, log in, and exchange messages instantly.

## 🚀 Features

- 👤 User Authentication (JWT based)
- 💬 Real-time messaging with Socket.IO
- 🔐 Secure login and session management
- 📨 Store chat history using MongoDB
- 🌐 Responsive frontend using React
- ✅ RESTful APIs for user and message handling

## 🛠️ Tech Stack

| Tech          | Usage                      |
|---------------|-----------------------------|
| **MongoDB**   | Database for users & messages |
| **Express.js**| Backend web framework        |
| **React.js**  | Frontend UI                  |
| **Node.js**   | Server runtime environment   |
| **Socket.IO** | Real-time messaging          |
| **JWT**       | Authentication mechanism     |
| **CSS**       | Styling and UI                |



## 🔧 Setup Instructions

1. Clone the repository
git clone https://github.com/Aman73802/chat-app.git
cd chat-app

2. Backend Setup:-
cd server
npm install
# Add a .env file with your MongoDB URI and JWT secret
npm start


3. Frontend Setup:-
cd client
npm install
npm start
